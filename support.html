Support

gLinux for Mac includes an Alpine Linux aarch64 command line. It requires an Apple Silicon Mac running macOS 14 or later. Open the app to start the shell; no Linux image download is required.

Files created in the shell stay in the app's local container. This edition does not include Docker compatibility or a Linux desktop.

How it fits together

A sandbox is one Linux command line and the files that belong to it. The drawing is a single sandbox inside the app. The one included with gLinux is Alpine Linux for aarch64, and that shell is ready when you open the app.

Sidebar and tabs

Sandboxes are listed on the left. Select one to use its terminal. The + beside the tabs opens another shell in the same sandbox. Closing a tab does not shut the sandbox down. Shut Down stops its programs and leaves its files. Sandboxes started by an MCP client are separate from the ones in the sidebar; the MCP tab lists them and does not open a shell.

The command

What you type runs as an aarch64 Linux program in that sandbox, inside the gLinux app. There is no second computer and no Linux desktop.

Files

The included sandbox keeps its files in the app’s local container on this Mac. On a new sandbox, Pro can place that sandbox’s storage in a folder you choose. A shared folder is separate: the Mac folder you pick stays where it is, and the sandbox sees it at /workspace.

Network

The included sandbox uses outbound network, so programs can reach the internet through NAT. Another sandbox can be limited to loopback, 127.0.0.1. Port mappings are optional and require outbound network.

Pro

The included Alpine sandbox does not need a subscription. Pro adds more sandboxes, other public Arm64 images, more than one CPU core, and a shared folder. Those other images download when you create the sandbox. An image has to be linux/arm64 and include /bin/sh.

This edition does not include Docker compatibility, a Linux desktop, or an x86 environment.

支持

结构

一个沙箱是一份 Linux 命令行，加上属于它的文件。下图是应用里的一个沙箱。gLinux 附带的是 aarch64 的 Alpine Linux，打开应用就能进入这个 shell。

列表和标签

沙箱列在左侧。选中一个，使用它的终端。标签旁的 + 会在同一个沙箱里再开一个 shell。关掉标签不会关闭沙箱。Shut Down 会停掉它的程序，文件仍然保留。MCP 客户端启动的沙箱与侧边栏里的沙箱分开；MCP 标签只列出它们，不会打开 shell。

命令

你输入的内容会作为 aarch64 Linux 程序，在这个沙箱里、在 gLinux 应用内运行。没有第二台电脑，也没有 Linux 图形桌面。

文件

附带的沙箱把文件放在这台 Mac 的应用容器里。新建沙箱时，Pro 可以把这个沙箱的存储放到你选择的文件夹。共享文件夹是另一件事：你选的 Mac 文件夹留在原处，沙箱里的路径是 /workspace。

网络

附带的沙箱使用向外的网络，程序通过 NAT 访问互联网。其他沙箱可以限制为仅本机回环 127.0.0.1。端口映射是可选的，并且需要向外的网络。

Pro

附带的 Alpine 沙箱不需要订阅。Pro 增加更多沙箱、其他公开的 Arm64 镜像、多于一个 CPU 核，以及共享文件夹。这些其他镜像在创建沙箱时下载。镜像必须是 linux/arm64，并且包含 /bin/sh。

本版本不提供 Docker 兼容、Linux 图形桌面或 x86 Linux 环境。
